## 03 · Selected Project

### [EduPOP](https://github.com/Eunhye-yoo/EduPOP)

**An education platform that connects test results to the next class and learning cycle**  
`Java` `Spring Boot` `MyBatis` `MySQL`

- **Product planning** — Proposed the original idea and helped define the core teacher/student learning flow and feature scope
- **Class operations** — Implemented class creation, student assignment, multi-instructor mapping, duplicate-assignment prevention, capacity validation, ownership checks, and soft delete
- **3-Minute Dashboard** — Built class/student performance summaries, weak-area analysis, and risk signals for pre-class decision support
- **Student Performance Report** — Implemented score trends and strength/weakness analysis, with reusable analytics logic for monthly reporting
