## 유은혜 | EunHye Yoo

**사람 사이에서는 팀의 소셜 허브, 일 앞에서는 먼저 움직이는 실행가.**

사람들과 편하게 어울리고 필요한 일에는 먼저 나섭니다. 다양한 문화권에서 생활하고 강사·학생·학부모와 함께하며, 상대의 상황과 이해도에 맞춰 소통하는 힘을 길렀습니다. 먼저 이야기를 듣고 필요한 내용을 쉽게 풀어 전달하며 여러 사람 앞에서 설명하거나 발표하는 데도 자신이 있습니다.

보안 솔루션 구축·기술지원 직무를 목표로 Linux·네트워크·AWS 환경 구성, 웹 서비스 개발·API 테스트를 해왔습니다. 직접 만들고 동작을 확인하고 막히는 부분은 해결해 가며 기술 역량을 쌓고 있습니다.
