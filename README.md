## 01 · About

Java·Spring 기반 웹 프로젝트를 개발하며 **기획한 기능이 데이터·API·서버 로직을 거쳐 실제 서비스로 동작하는 과정**을 이해하고 있습니다.

## 03 · Selected Project

**시험 결과를 다음 수업과 학습으로 연결하는 교육 플랫폼**  
`Java` `Spring Boot` `MyBatis` `MySQL`

- **기획 주도** — 아이디어를 제안하고, 교사·학생의 학습 흐름과 핵심 기능을 구체화
- **반 운영 기능** — 반 생성과 수강생·다중 강사 매핑, 중복 배정 및 운영 상태 관리 구현

- **개인 성적표** — 성적 추이와 강점·취약 영역을 시각화하고, 월간 리포트에서도 재사용할 수 있도록 분석 로직 구성
